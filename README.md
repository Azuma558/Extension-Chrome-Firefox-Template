# 🧩 Extension Chrome & Firefox – Template

Un template de base pour développer facilement vos propres extensions compatibles avec **Google Chrome** et **Mozilla Firefox**.

Ce projet fournit une structure prête à l'emploi avec plusieurs fonctionnalités déjà intégrées pour vous permettre de démarrer rapidement votre développement.

## ✨ Fonctionnalités intégrées

- 🍪 **Suppression des cookies** : fonctionnalité intégrée pour supprimer les cookies.
- 🔎 **Détection de mots-clés** : système permettant de détecter automatiquement des mots-clés définis.
- 🌐 **Compatibilité multi-navigateurs** : conçu pour fonctionner sur Chrome et Firefox.
- 🛠️ **Structure personnalisable** : adaptez librement le code et ajoutez vos propres fonctionnalités.

## 🚀 Utilisation

1. 📥 Clonez ou téléchargez le dépôt GitHub.
2. 📂 Ouvrez le dossier du projet.
3. 📝 Modifiez le code selon vos besoins.
4. 🧩 Chargez l'extension dans votre navigateur :
   - **Chrome** : rendez-vous sur `chrome://extensions/`, activez le mode développeur, puis cliquez sur « Charger l'extension non empaquetée ».
   - **Firefox** : rendez-vous sur `about:debugging#/runtime/this-firefox`, puis cliquez sur « Charger un module complémentaire temporaire ».

## 🎨 Personnalisation

Ce template est conçu pour être facilement modifiable.

Ajoutez vos propres fonctionnalités, adaptez l'interface et personnalisez le comportement de l'extension selon vos besoins.
